# storeIQ-

Overview — 

KPI cards (total revenue, avg daily transactions, avg staff, peak day) + correlation matrix with bar gauges + sales vs staff scatter plot + day-of-week bar chart
Trends — 

Daily sales line with 7-day & 30-day moving averages + monthly seasonality bar chart


Staffing — 

Staff vs transactions by weekday + plain-English staffing insights based on correlation strength


Predictor — 
7-card traffic forecast for the next week (High / Normal / Low labels) using linear regression on the trailing 30 days with day-of-week multipliers
